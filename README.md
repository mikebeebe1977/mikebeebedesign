# mikebeebedesign.com

Personal portfolio site for Mike Beebe. Plain HTML and CSS, no build step, hosted on GitHub Pages.

## Files

- `index.html` – home page (work, about, experience, contact)
- `mcdonalds-mobile-ordering.html`, `northern-trust.html`, `fordworks.html` – case study pages
- `ai-and-design.html` – AI & Design page
- `styles.css` – all styling; colors and fonts are variables at the top
- `images/` – project images

## Editing

1. Create a branch, edit the HTML or CSS, and preview by opening `index.html` in a browser.
2. Commit, push, and open a pull request. Merging into `main` publishes the site.

Search for `TODO` to find placeholders that still need real content.
